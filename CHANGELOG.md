# Changelog

All notable changes to this project are documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions
follow a `major.minor.patch` scheme: while the project is young, minor releases
may include breaking changes, each listed under a Breaking heading.

## [Unreleased]

## [0.5.0] - 2026-07-19

### Changed

- Index link rows parse at the block level and wrap to the `--wrap` column.

## [0.4.0] - 2026-07-19

### Changed

- Internal refactor; no behavior changes.

## [0.3.0] - 2026-07-18

### Changed

- Formatter output is a fixed point of the wiki reader.

## [0.2.1] - 2026-07-17

### Fixed

- Index link wrapping.

## [0.2.0] - 2026-07-17

### Fixed

- ATX headings keep their original inline face verbatim.

## [0.1.0] - 2026-07-09

No changes from 0.0.0; version bump only.

## [0.0.0] - 2026-07-09

Initial release: mdformat parser-extension plugin preserving wikilinks,
frontmatter, and the index delimiter.
